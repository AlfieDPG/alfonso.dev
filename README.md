# Portfolio de Alfonso del Pino

Portfolio estático en HTML, CSS y JavaScript, sin dependencias ni proceso de compilación. Se publica gratis con GitHub Pages.

## Añadir un proyecto nuevo

En `index.html`, dentro de `<section id="proyectos">`, sustituye uno de los huecos `<div class="slot">` por un `<article class="featured">` copiado del de LockeDex y cambia imagen, textos, tecnologías y enlaces.

## Publicarlo en GitHub Pages

1. Crea un repositorio en GitHub y sube estos archivos a la rama `main`.
2. En el repositorio, abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.
5. GitHub publicará el sitio y mostrará su dirección en la misma página de Pages.
